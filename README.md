# Estate Law Aid v1.1.89

Estate Law Aid provides free, plain-language estate-planning and probate preparation, official-resource routing, and a source-tracked professional directory. It is not a law firm and does not provide legal advice.

## Current release

- 968 public-source unclaimed profiles: 621 individual attorneys and 347 firms.
- 1,381 HTML routes: 1,132 indexable and 249 noindex.
- Public directory discovery surfaces now show the exact current inventory and source-maintenance summary: 464 fresh, 504 watch, and 0 stale.
- Directory currentness bands are maintenance signals only; they are not rankings, credential findings, availability promises, or recommendations.
- Profile claiming, correction, comparison, verification preparation, consultation planning, and source-refresh workflows remain separate from representation and opportunity eligibility.
- OpenAI remains central-gateway-only and tested dark; no OpenAI, Stripe, database, email, Render, or GitHub secret belongs in this portal.
- Production deployment and all external live-service states remain unproven and unauthorized.
