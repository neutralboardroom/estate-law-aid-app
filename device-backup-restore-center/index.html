browser-local continuity

Review the whole workspace before restoring anything.

This tool reads a user-selected Estate Law Aid JSON backup in this browser. It previews safe additions, duplicates, conflicts, invalid entries, and possible credential-bearing records before any change.

Do not include passwords, PINs, authentication codes, private keys, seed phrases, Social Security numbers, or full account numbers. Nothing is uploaded or sent. Existing browser keys are never overwritten automatically.

1. Inspect a backup

No backup inspected.

2. Review every record

Only records marked safe addition can be selected. Conflicts, duplicates, prohibited records, and invalid records cannot be restored.

3. Save evidence or restore selected additions

The downloadable review report lists record names, storage scope, status, size, and selected state. It deliberately excludes stored values.

Undo is available only for additions restored during the current page session and only while their values remain unchanged.

Important restoration limits

  • Only managed Estate Law Aid local- or session-storage keys are eligible.
  • Conflicts are not restored. Export both versions and choose deliberately.
  • Compact count-only summaries can restore only the compact summary; they cannot recreate detailed source text or records that were never saved.
  • The review report excludes stored values and is not itself a restorable backup.
  • The tool does not validate legal documents, recover deleted server data, transmit files, create an account, contact a professional, or make a lead.
