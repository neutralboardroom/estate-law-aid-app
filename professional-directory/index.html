Clear professional boundaries

Profiles, contact requests, review options, and attorney engagements stay separate.

For the public

Use profiles and review options as a starting point, then confirm credentials, fit, fees, availability, and engagement terms directly.

For professionals

Claim and correction preparation is available in the browser. Identity, authority, credential verification, publication, billing, and inquiry activation remain separate and are not live.

For attorneys

Legal advice begins only after conflict review, defined scope, engagement terms, attorney acceptance, and secure document access.

How to use the directory

Compare practice fit, location, language, and profile status before requesting contact.

Useful filters

Look for estate planning, probate, trust, elder-law, administration, or document-review fit.

Clear profile labels

Unclaimed profiles, claimed profiles, paid enhancements, and sponsorship should be labeled without implying endorsement.

Engagement is separate

Viewing a profile or requesting contact does not create an attorney-client relationship. Conflict, scope, terms, and attorney acceptance come later.

How profiles should be understood

Profile information should be verified, labeled, and kept current. A profile does not mean the professional is available, endorsed by Estate Law Aid, or already representing you.

For professionals and firms

Profiles should help the right people understand your practice without implying representation too early.

Attorneys and firms can request profile claims, corrections, firm association review, and future enhanced-profile options. Organic directory information, paid profile tools, sponsored placement, contact requests, and attorney engagement stay clearly separated.

Sourced profiles

Search 1,267 public-source profiles responsibly.

Public-source profiles show source facts, review dates, claim status, geography, and correction options. A profile is not an endorsement, ranking, availability promise, or attorney-client relationship.

Current directory inventory: 1,267 profiles — 910 individual attorneys and 357 firms. Source review dates: 462 fresh, 805 watch, 0 stale. These maintenance bands are not rankings, credential findings, availability promises, or recommendations.

Jurisdiction matches: 816 New York, 175 New Jersey, 93 Connecticut, 3 Pennsylvania, and 5 Massachusetts. A profile may appear in more than one jurisdiction based on published office and license fields. These matches are not credential verification, rankings, availability promises, or recommendations.

Responsive browsing: filters search all 1,267 profiles, while matching cards appear 24 at a time. Use “Show more profiles” to continue. This batching does not rank, hide, or remove profiles.

User-controlled order: choose Directory order, Name A–Z, or Name Z–A. Sorting applies to the complete matching set before 24-profile batching. It is not a quality, payment, popularity, availability, or recommendation ranking.

User-controlled results per batch: choose 24, 48, or 96 visible profiles at a time. Filters and sorting still evaluate the complete 1,267-profile dataset, and every match remains reachable. This preference does not rank, suppress, remove, recommend, or change profile eligibility.

Browser-local view: choose Standard cards or Compact cards. Standard remains the default. Compact view changes spacing only; it does not change profile content, matching, order, batching, reachability, ranking, recommendation, or eligibility. The choice is stored only in this browser when storage is available.

Directory order preserves the packaged directory sequence, except an active ZIP-radius search keeps its existing nearest-distance order. Name sorting uses the published profile name with a stable slug tie-breaker.

Results per batch controls how many matching cards are shown at once on this page. It does not reduce the search universe, alter the selected order, or hide profiles from continued keyboard-accessible browsing.

View changes card spacing only. It keeps every field, action, match, selected order, and batch reachable. The preference stays in this browser only when browser storage is available.

Search tip: Use the jurisdiction filter for New York, New Jersey, Connecticut, Pennsylvania, or Massachusetts. A profile may appear in more than one jurisdiction; use the area, ZIP, county, city, and need controls for narrower searching. Try a ZIP, county, city, or plain-language need such as “probate,” “trusts,” “elder law,” or “executor help.”

Area-filter clarity: County choices that share a name across states are state-qualified. “Middlesex County, NJ” and “Middlesex County, CT” are separate filters. Area matching uses published city, county, state, office, and service-area fields; it is not credential verification, ranking, availability, or recommendation.

ZIP/radius filtering uses approximate public office or service-area coordinates. Confirm jurisdiction, credentials, conflicts, availability, fees, and engagement terms separately.
