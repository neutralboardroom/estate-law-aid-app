Output formats

Customer-friendly path

  1. Name it. Matter name plus draft name so work can be resumed.
  2. Organize it. Pick document path, sections, and related copies.
  3. Save it. Store as a browser-saved draft or work-vault record.
  4. Export it. Print/save PDF or download Word-compatible, RTF, TXT, HTML, JSON, or Google Docs import file.
  5. Review it. Optional organization review, preparation review, or attorney review.
