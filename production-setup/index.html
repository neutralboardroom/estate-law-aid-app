Production setup checklist

Production Setup: What Must Be Real Before Launch

This page converts the audit gaps into implementation tracks so the platform can move from static prototype to production with real accounts, secure uploads, OCR, AI, attorney review, payment, and notifications.

1. Secure accounts

  • Auth provider or custom auth
  • MFA option
  • Role permissions
  • Session security
  • Password reset
  • Deadline tracker
  • Document quality control
  • Assignment workflow
  • Notification preferences

2. Database

  • Users
  • Cases
  • Documents
  • Tasks
  • Messages
  • Audit logs

3. Secure uploads

  • Encrypted storage
  • Virus scanning
  • File type limits
  • Retention rules
  • Access logs

4. OCR / extraction

  • PDF text extraction
  • Image OCR
  • Page order detection
  • Human quality review
  • Extracted fact review

5. AI providers

  • Smarter Justice central gateway
  • Registered Estate tool
  • Schema and source validation
  • Injection isolation
  • Deterministic fallback
  • Kill and degraded mode

6. Attorney workflow

  • Conflict check
  • Scope
  • Engagement terms
  • Review status
  • Attorney notes

7. Payments

  • Stripe products
  • Payment status
  • Refund policy
  • Receipts
  • Review release gates

8. Notifications

  • Email
  • SMS optional
  • Staff alerts
  • Attorney alerts
  • Deadline reminders
Plan. Protect. Prepare.
