Attribution and source rules

Protect the first eligible referral and keep QR tracking clean.

This page explains the preview logic behind referral-code capture, credit lock, QR scans, assisted starts, and reward review.

Referral DashboardQR ToolsReward Ledger

First eligible code locks

When a user arrives through a tracked referral link, the first code is stored in the browser preview. A later link should not silently overwrite it.

QR contains no sensitive facts

The QR should carry only the referral code, starting path, source, and campaign marker — not family, asset, health, probate, or legal facts.

Staff can review exceptions

Production should allow owner/staff review for duplicate accounts, self-referrals, professional restrictions, refunds, chargebacks, and unclear attribution.
