Update a Will or Trust From Photos

Yes — this platform should allow users to start an amendment/update intake using only pictures from a mobile phone, as long as every page is clear, complete, and in order. Upload photos of your existing will, trust, POA, health care proxy, advance directive, deed, beneficiary form, or probate paper, then answer simple questions about what you want changed.

Workspace limitation: In live service, photo-only editing requires secure upload, OCR/document extraction, human/attorney review controls, and state-specific document assembly. this workspace stores only selected file metadata and your answers. It does not read the photos, extract text, redline the document, or create a final valid legal amendment.

Photo tips before uploading

  • Photograph every page, including signature, witness, notary, schedule, exhibit, and amendment pages.
  • Keep pages flat, well-lit, and fully inside the camera frame.
  • Avoid glare, shadows, fingers, folded corners, blur, and cut-off page numbers.
  • Upload pages in order if possible, or name files with page numbers.
  • Use copies only. Keep originals safe.
